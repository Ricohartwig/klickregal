# klickregal

klickregal.de

Browserbasierter 3D-Konfigurator für modulare Alu-Nutprofil-Schranksysteme.

## Entwicklung

```bash
npm install
npm run dev
```

Öffnen: [http://localhost:3000](http://localhost:3000)

## Skripte

- `npm run dev` — Entwicklungsserver
- `npm run build` — Produktionsbuild
- `npm run typecheck` — TypeScript (`tsc --noEmit`)
- `npm run test` — Vitest
- `npm run lint` — ESLint
